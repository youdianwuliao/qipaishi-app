# 🀄 棋牌室

> 纯局域网多人棋牌 App，开箱即玩，无需服务器

## ✨ 功能

- 🃏 **斗地主** — 12 种牌型、叫地主、炸弹翻倍、积分零和结算
- 🀄 **麻将** — 136 张标准、递归胡牌判定、七对子、十三幺、吃碰杠
- 🔍 **自动发现** — 同一 Wi-Fi 下打开即看到房间
- 💰 **积分系统** — 初始 10000 分，底注 1000，破产重置
- 🚫 **零依赖** — 不需要服务器、不需要注册、不需要外网

## 🏗️ 技术栈

| 层 | 技术 |
|----|------|
| 语言 | Kotlin |
| UI | Jetpack Compose |
| 房间发现 | UDP 组播 (239.255.0.1:9527) |
| 游戏通信 | TCP Socket (JSON) |
| 最低版本 | Android 8.0 (API 26) |

## 🚀 快速开始

1. Android Studio 打开项目
2. Sync Gradle
3. 两台手机连同一 Wi-Fi
4. Run → 一台创建房间，另一台自动看到 → 加入 → 开始！

## 📁 项目结构

```
qipaishi-app/
├── app/
│   ├── build.gradle.kts
│   └── src/main/java/com/qipaishi/

│       ├── core/                       # 协调层
│       │   ├── ScoreManager.kt          # 积分管理
│       │   ├── DoudizhuRoomHost.kt      # 斗地主房间主机

│       ├── network/                    # 网络层
│       │   ├── RoomBroadcaster.kt       # UDP 组播广播

│       │   ├── GameServer.kt            # TCP 服务端
│       │   ├── GameClient.kt            # TCP 客户端
│       │   └── protocol/Messages.kt     # JSON 协议定义
│       ├── game/
│       │   ├── doudizhu/model/          # 牌、牌堆、牌型、比较器
```
